## 4CPA TraceMap – Desktop-App

Verfolgt Webadressen (Traceroute) und E-Mails (Header) und zeigt die Route auf einer Weltkarte. Läuft lokal auf deinem Rechner.

| System | Datei |
|---|---|
| Windows 10/11 (64 Bit) | `4CPA-TraceMap-windows-x64.zip` |
| Linux (64 Bit) | `4CPA-TraceMap-linux-x64.tar.gz` (Programm `traceroute` nötig) |
| macOS (Apple Silicon) | `4CPA-TraceMap-macos-arm64.zip` |

**Wichtig:** Die Apps sind nicht signiert. Windows (SmartScreen) und macOS (Gatekeeper) warnen deshalb beim ersten Start – siehe README, Abschnitt «Installation».
Die Datei `SHA256SUMS.txt` enthält die Prüfsummen zum Vergleichen.
Standortdaten aus dem Netz (ip-api.com); mit einer eigenen MaxMind-GeoLite2-Datenbank im Datenschutzmodus lokal – siehe README.
